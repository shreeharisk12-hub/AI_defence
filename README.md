# 🎯 AI_defence: Multi-Domain Threat Detection System

## 🚀 Overview
A rapid-deployment AI defense solution engineered during a 24-hour national-level hackathon. `AI_defence` integrates **YOLO object detection** with **AWS cloud infrastructure** and a tactical web dashboard to provide real-time identification of military assets—including tanks, planes, ships, and thermal landmines. 

## ✨ Features
*   **Multi-Domain Asset Detection:** Accurately identifies and tracks diverse military targets using custom-configured YOLO models.
*   **Tactical Web Dashboard:** A high-tech, military-style frontend interface featuring rolling threat feeds and confidence scoring for actionable intelligence.
*   **Real-Time Cloud Synchronization:** Leverages AWS infrastructure to ensure seamless, real-time intelligence data synchronization across servers.
*   **High-Speed Inference:** Optimized for rapid data processing, a critical requirement for time-sensitive situational awareness.

## 🛠️ Tech Stack
*   **Core Logic:** Python
*   **Object Detection Model:** YOLO (You Only Look Once)
*   **Cloud Infrastructure:** AWS
*   **Data Processing & Visualization:** OpenCV, NumPy, Pandas, Matplotlib
*   **Frontend Interface:** HTML, CSS
